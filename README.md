# See You Again
本游戏为崩坏星穹铁道同人二创，厄夏CP向（白厄x那刻夏），多结局分支文字游戏。

安装方法：
- Windows:
解压后双击see-you-again.exe文件即可游玩，请勿自行修改目录下的文件。
- MacOS:
解压后双击see-you-again app文件，弹出文件或目录授权确认时请点击确认。
- Android:
双击apk文件安装至移动端，双击后在桌面找到See You Again的app，打开即可游玩。
